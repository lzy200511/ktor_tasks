# Task 1.1

1. Create the basic structure of an HTML document in file `document.html`.
   Your document should include a `head` element and an empty `body` element.
   The `head` element should include the `meta` and `title` elements
   described in the Guide. Use "Task 1.1" as the title.

2. Check the code using the [W3C Markup Validator][val], fixing any errors
   that you find.

3. Open the file in a web browser. You should see a blank page, but the
   text you chose for the `title` element should be displayed in the
   browser tab.


[val]: https://validator.w3.org/
