# Task 2.3

1. In the `tasks/task2_3` directory of your repository, create an HTML file
   named `pico.html`. Put the 'starter code' described in the Guide in
   this file. Use "Task 2.3" as the document title.

2. Add some content to the document. At minimum, this should include

   * Several paragraphs of text, including hyperlinks
   * `h1` and `h2` headings
   * A form, including a button

   You can add other elements (e.g., a table) if you wish.

   Open the document in a web browser to see what it looks like.

3. Experiment with customizing the elements, as described in the Pico
   documentation. For example, try using some of the alternative styles for
   links and buttons.

4. Experiment with changing the page layout. Try changing the `class` attribute
   of the `main` element to be `container-fluid` instead of `container`.
   Then try using a grid to create a two-column layout.

5. Finally, experiment with some of the special components provided by Pico,
   again using the documentation as your guide.

   (At minimum, look at the first four of the listed components, along
   with `nav`.)
