# Task 4.7

This task is based on the solution to Task 4.6.2. You goal is produce an
alternative implementation of the dice rolling application, in which form
data are sent to the server via a POST request.

This will necessitate changes to the template files `form.peb` and
`result.peb`, as well as the routing in `Routing.kt`.

See the Ktor Web Development Guide for further details.
