# Task 4.5.2

Run the application with

    ./run

You should see a page of HTML when you visit `http://localhost:8080`.

Run the tests with

    ./kotlin test

Edit `index.html`, in the `resources/static` directory, then make the changes
suggested in the Ktor Web Development Guide and note what effects they have on
test results.

Finally, improve the tests by using the JSoup parser, as indicate in the
Ktor Web Development Guide. Repeat your changes to `index.html` and note what
effects they have on test results.
