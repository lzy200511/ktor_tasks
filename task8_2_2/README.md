# Task 8.2.2

The dice rolling application, implemented as a true **single-page application**
using the [htmx][hx] library. This version does not require a full page
reload in order to display the results of a dice roll.

Run the application with

    ./run

(Adjust as necessary if using Microsoft Windows.)

See the Ktor Web Development Guide for further details.


[hx]: https://htmx.org/
