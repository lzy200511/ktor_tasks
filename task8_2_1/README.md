# Task 8.2.1

An alternative version of the dice rolling application, in which the form
for selecting dice and the results of a roll are displayed on the same
page. A full page reload is required to update the UI every time dice are
rolled. See Task 8.2.2 for an improved version that functions as a true
**single-page application**.

Run the application with

    ./run

(Adjust as necessary if using Microsoft Windows.)

See the Ktor Web Development Guide for further details.
